The job

The starter has no answer key. The submission is the repository plus a 3 to 5 minute video. Show how a match, a comparison, and a citation were checked.

Required work

  1. Extract the 100 shared scans with Parse 3.5. A page can hold several entries. An entry can continue onto the next page. Some scans are blank or hard to read.
  2. Find candidate Wikipedia articles and decide which matches to keep.
  3. Use the team embedder and reranker in that decision.
  4. Compare vocabulary, frequencies, or topics. Cite the source text.
  5. Publish a static site whose Britannica text is compiled LaTeX.
  6. Run Hermes on Super 3.5 VL with the comparison tools.
  7. Keep three success cases and three failure cases from saved runs.

Improvements worth making

Send the scan to the VL models

Embed and rerank currently take entry text against title plus excerpt. Both models accept an image. A crop of the scan can recover a damaged headword such as PHILLOOGY, which text search misses. Keep the image checksum with the vector.

Check the 39 accepts by hand

The logit floor of −6.0 and the title floor of 0.75 come from one calibration pass. List pages such as “Willin'” can still pass when the title string is close and the page is not labelled “(disambiguation)”. Sample accepted and rejected pairs and record the misses.

Join more continuations

82 of 241 entries are untitled continuations, and only 2 were joined to a previous page. Most of those 53 skips are short or untitled text. A running header plus consecutive row index can attach more of that text before search.

Treat the two Parse failures as plates

Rows 452 and 2243 hit the token limit with an incomplete reply. Mark a blank cover or an engraved plate as a page status and stop retrying the same request. The current skip only drops protocol errors.

Clean the vocabulary before log-odds

19.6% of Britannica tokens sit outside the word list, so OCR noise can dominate the distinctive terms. Historical spelling logged zero changes. Expand printed abbreviations such as “Brit.” before counting. The earlier corpus answer treated “brit” as an OCR fragment. In the source it is the abbreviation in WEIGHTS AND MEASURES.

Make search tolerate OCR

challenge_search uses word overlap. A fuzzy headword, and a second query with the running header, would stop the agent from reporting that an entry is absent. Require challenge_read before the agent explains a corpus term.

Say what the low overlap means

Mean Jaccard of the top 100 terms is 0.043. That can be real drift between an old encyclopaedia and a modern article, or it can be length and OCR. Report both, with the length ratio already stored on each pair. BERTopic is optional. If you keep word frequencies, say why in the submission.
